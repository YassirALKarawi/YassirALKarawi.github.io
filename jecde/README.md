# JECDE journal website and LaTeX template

Journal of Electrical, Computer and Digital Engineering.

Static site: open index.html, or serve this directory with a static web server.
Author resources: templates.html and downloads/. Editable LaTeX files: latex/.
Rebuild HTML with Python 3: python build.py (creates dist/). Keep the downloadable resources when deploying.

The journal is in its founding stage. Submissions and payments are not active.
The Sites publication workflow is separate from GitHub; no automatic Sites synchronization is configured.
