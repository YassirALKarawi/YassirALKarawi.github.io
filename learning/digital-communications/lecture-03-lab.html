3.1 PCM: send a number for every sample

Pulse-code modulation (PCM) represents each sample of an analog message by a binary word. Sampling selects the time, quantization selects an allowed amplitude, and encoding labels that amplitude with bits.

The anti-alias low-pass filter (LPF) limits the input bandwidth before sampling. The receiver makes bit decisions, groups bits into words, converts the words to reconstruction levels, and filters the resulting waveform.

A digital-to-analog converter (DAC) produces the corresponding output level. Regeneration can clean up correctly detected bits. It cannot undo the quantization error already introduced at the transmitter.

3.2 Levels, thresholds and binary labels

A uniform quantizer divides a specified amplitude range into equal intervals. A decision threshold separates adjacent intervals. The reconstruction level is the value used to represent an interval.

L=2^{\nu},\qquad \Delta=\frac{m_{\max}-m_{\min}}{L}

Here ν is the number of bits per sample, L is the number of levels, and Δ is the interval width in volts. In a midpoint quantizer, use the interval centre, not its lower boundary.

i=\operatorname{clip}\!\left(\left\lfloor\frac{m-m_{\min}}{\Delta}\right\rfloor,0,L-1\right),\qquad m_q=m_{\min}+(i+\tfrac12)\Delta

The clipping rule maps out-of-range inputs to an end level. At the upper range endpoint, the final code is used. Saturation beyond the range can create overload distortion.

3.3 Quantization error and noise

Quantization error is the difference between the reconstructed sample and the original sample. This lecture uses e = mq − m. Stating the sign convention prevents inconsistent solutions.

e=m_q-m,\qquad |e|\leq\frac{\Delta}{2}

The half-step bound applies to rounding within the input range. It does not apply to arbitrary overload inputs.

Example 3.2 · Error for the 3.2 V sample

e=3.4375-3.2=0.2375\;\mathrm{V}

\Delta/2=0.3125\;\mathrm{V}

The positive error means the reconstructed sample is above the input. Its magnitude is inside the half-step bound.

If the error is approximately uniform over −Δ/2 to +Δ/2, its mean is zero and its mean-square value is:

\sigma_e^2=\frac{1}{\Delta}\int_{-\Delta/2}^{\Delta/2}e^2\,de=\frac{\Delta^2}{12}

This is a noise model, not a guarantee for every waveform. It works best when many quantization intervals are occupied and the error is not strongly correlated with the input.

Example 3.3 · Noise estimate

\sigma_e^2=0.625^2/12=0.032552\;\mathrm{V}^2

Use V² for a mean-square voltage. Conversion to watts requires a resistance.

3.4 Bit rate, bit duration and bandwidth

Each sample produces ν bits. With fs samples each second, the payload rate r is νfs. Framing and error-control bits must be counted separately.

r=\nu f_s,\qquad T_b=\frac1r,\qquad B_{\min}=\frac r2

Bmin is the ideal one-sided baseband bandwidth for binary Nyquist signaling. With raised-cosine roll-off α, B = (1 + α)r/2. Rectangular bit pulses have no strict finite bandwidth.

3.5 Signal-to-quantization-noise ratio

SQNR compares signal mean-square value Pm with mean-square quantization error. It excludes channel noise.

\mathrm{SQNR}=\frac{P_m}{\Delta^2/12},\qquad \mathrm{SQNR}_{dB}=10\log_{10}(\mathrm{SQNR})

For a sine of peak A, Pm = A²/2. For a symmetric quantizer spanning −AFS to +AFS, Δ = 2AFS/2ν. Substitution gives:

\mathrm{SQNR}_{dB}\simeq6.02\nu+1.76+20\log_{10}(A/A_{FS})

Only a full-scale sine has A = AFS. The familiar 6.02ν + 1.76 result should not be applied unchanged to arbitrary signals.

Example 3.6 · Ten-bit full-scale sine

\mathrm{SQNR}_{dB}\simeq6.02(10)+1.76=61.96\;\mathrm{dB}

Example 3.7 · At least 40 dB for a full-scale sine

\nu\geq(40-1.76)/6.02=6.35

Round upward because this is a minimum quality requirement.

\nu=7,\qquad L=128,\qquad \mathrm{SQNR}\simeq43.90\;\mathrm{dB}

Reduced sine amplitude

Halving the input amplitude quarters the signal power while the quantizer step stays fixed.

20\log_{10}(0.5)=-6.02\;\mathrm{dB}

The predicted SQNR falls by approximately 6 dB.

3.6 Choose the bit count under constraints

A minimum accuracy or SQNR requirement gives a lower bound on ν. A maximum available bit rate gives an upper bound. A design is feasible only if the bounds overlap.

\nu_{\min}=\left\lceil\frac{Q_{dB}-1.76}{6.02}\right\rceil,\qquad \nu_{\max}=\left\lfloor\frac{r_{\max}}{f_s}\right\rfloor

Accuracy: error no larger than 0.1% of peak full scale

For a symmetric midpoint quantizer, the normalized half-step is 1/L.

1/L\leq0.001\;\Rightarrow\;L\geq1000

Choose the next binary level count: L = 1024, so ν = 10 bits.

Example 3.12 · A 10.2 MHz television message with 512 levels

\nu=\log_2(512)=9

f_{s,N}=2(10.2)=20.4\;\mathrm{Msample/s}

r_N=9(20.4)=183.6\;\mathrm{Mbit/s}

B_{\min,N}=91.8\;\mathrm{MHz}

These are ideal Nyquist limits. A practical sampling margin increases the required rate.

3.7 Non-uniform quantization and companding

Non-uniform quantization uses smaller input intervals for some amplitudes and larger ones for others. Small speech amplitudes can benefit from finer relative precision.

Companding performs compression before uniform quantization and inverse expansion after decoding. It improves the allocation of levels over a wide amplitude range, but does not eliminate quantization error.

F_\mu(x)=\operatorname{sgn}(x)\frac{\ln(1+\mu|x|)}{\ln(1+\mu)},\qquad |x|\leq1F_\mu^{-1}(y)=\operatorname{sgn}(y)\frac{(1+\mu)^{|y|}-1}{\mu}

x and y are normalized amplitudes. μ controls compression. The μ = 0 limit is linear. The continuous formula explains the principle, while exact G.711 mappings use specified segmented codes.

Example 3.16 · μ = 255 and x = 0.1

F_\mu(0.1)=\frac{\ln(26.5)}{\ln(256)}\simeq0.59099

Compression maps a small input to a larger fraction of the normalized output range. The inverse function restores the original amplitude scale.

3.8 A-law and comparison with uniform PCM

F_A(x)=\operatorname{sgn}(x)\begin{cases}\frac{A|x|}{1+\ln A},&|x|<1/A\\\frac{1+\ln(A|x|)}{1+\ln A},&1/A\leq|x|\leq1\end{cases}

A-law uses a linear region near zero and a logarithmic region for larger magnitudes. First compare |x| with 1/A, then select the branch. The branches meet continuously at the boundary.

Select the correct branch for A = 87.6 and x = 0.01

1/A\simeq0.01142

Since 0.01 < 0.01142, use the linear branch.

F_A(0.01)=\frac{87.6(0.01)}{1+\ln87.6}\simeq0.1601

Uniform PCM has constant input-domain resolution. Companded PCM has amplitude-dependent input resolution. A better weak-signal performance does not imply a better full-scale sine SQNR.

Worked practice

Find the step and bit rate for 3-bit PCM over −1 to +1 V at 8 ksample/s.

Levels: L = 2³ = 8.

Step: Δ = 2/8 = 0.25 V.

Bit rate: Rb = 3 × 8000 = 24 kbit/s.

What happens when one bit is added?

The number of levels doubles.

At fixed input range the step halves.

Under the uniform-error model the noise power becomes one quarter, giving about 6 dB improvement.
