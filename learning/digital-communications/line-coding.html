01

Start with meaning

Why this topic matters

A line code converts a bit sequence into voltage pulses suitable for a physical baseband channel. A useful code balances bandwidth, synchronization, DC content, power and the ability to reveal transmission errors.

INTUITION

The same bits can be spoken with different electrical accents. Manchester speaks more rapidly but carries its own clock; AMI alternates marks to reduce DC and exposes some violations.

02

Mathematical foundation

Equations you can trust

Read every formula as a relationship between physical quantities. Check units before inserting numbers, and keep linear ratios separate from decibels.

01

Polar NRZ

a_k\in\{-A,+A\}

Both logic values use equal and opposite levels.

02

AMI rule

1\rightarrow\pm A\;\text{alternately},\quad0\rightarrow0

Successive marks have alternating polarity.

03

PSD principle

S_x(f)=\frac{|P(f)|^2}{T_b}S_a(e^{j2\pi fT_b})

Pulse spectrum and symbol statistics jointly determine PSD.

04

Bit period

T_b=1/R_b

Faster data compresses every pulse in time.

How to study the mathematics

First name every symbol, then state the assumptions, substitute values with units, and only then calculate. A numerically correct result without assumptions is not a complete engineering answer.

From symbols to numbers

Fully worked examples

Worked example 1

Manchester transitions

Problem

Encode bits 1 0 1 using 1=high-to-low and 0=low-to-high.

  1. Each bit has a guaranteed mid-bit transition
  2. 1: H→L, 0: L→H, 1: H→L
AnswerThe waveform is self-clocking but requires more bandwidth than NRZ.
Worked example 2

AMI sequence

Problem

Encode 1 1 0 1 0 1 with the first mark positive.

  1. Alternate polarity only for ones
  2. +A, −A, 0, +A, 0, −A
AnswerThe running mark polarity remains balanced.
06

Deliberate practice

Problems with guided solutions

Attempt each problem on paper before opening the solution. Include units and state the formula you selected.

01Which common code guarantees a mid-bit transition?
Solution

Manchester.

02Encode 1101 in AMI beginning with +A.
Solution

+A, −A, 0, +A.

03Why is DC content undesirable?
Solution

Transformers and AC-coupled channels cannot pass DC reliably.

04Which needs more bandwidth, NRZ or Manchester?
Solution

Manchester, because it can transition twice per bit.

05What can an AMI bipolar violation indicate?
Solution

An error or a deliberate scrambling pattern.
