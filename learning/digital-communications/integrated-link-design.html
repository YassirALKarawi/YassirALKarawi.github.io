01

Start with meaning

Why this topic matters

Real communication design is a chain of coupled choices. A higher modulation order may save bandwidth but demands more SNR and linearity; stronger coding lowers required SNR but adds redundancy and delay. This capstone lesson makes every assumption and unit explicit.

INTUITION

A link is only as strong as its tightest budget: bandwidth, power, delay, computation or reliability. Good design does not maximize one number; it satisfies all constraints with measurable margin.

02

Mathematical foundation

Equations you can trust

Read every formula as a relationship between physical quantities. Check units before inserting numbers, and keep linear ratios separate from decibels.

01

Coded symbol rate

R_s=\frac{R_{info}}{R_c\log_2M}

Coding overhead and constellation size jointly set baud.

02

Raised-cosine RF bandwidth

B_{RF}\approx(1+\alpha)R_s

Common passband bandwidth approximation.

03

Noise power

N=kTBF

Use linear noise factor F; k is Boltzmann's constant.

04

Received power

P_r=P_tG_tG_r\left(\frac{\lambda}{4\pi d}\right)^2/L

Free-space core with additional loss factor L.

05

Design margin

M_d=(E_b/N_0)_{available}-(E_b/N_0)_{required}

All values in dB; positive margin is required.

How to study the mathematics

First name every symbol, then state the assumptions, substitute values with units, and only then calculate. A numerically correct result without assumptions is not a complete engineering answer.

From symbols to numbers

Fully worked examples

Worked example 1

Bandwidth closure

Problem

Rinfo=12 Mbit/s, Rc=3/4, 16-QAM and α=0.25. Find Rₛ and BRF.

  1. k=4
  2. Rₛ=12/(0.75×4)=4 Mbaud
  3. BRF≈1.25×4
AnswerRequired RF bandwidth≈5 MHz.
Worked example 2

Margin

Problem

Available Eᵦ/N₀=11.5 dB; required=8 dB; implementation loss=1.5 dB.

  1. Effective required=8+1.5=9.5 dB
  2. Margin=11.5−9.5
AnswerDesign margin=2 dB.
06

Deliberate practice

Problems with guided solutions

Attempt each problem on paper before opening the solution. Include units and state the formula you selected.

01What happens to Rₛ if code rate decreases?
Solution

It increases for fixed information rate and M.

02What does larger α trade?
Solution

More bandwidth for shorter tails and easier timing implementation.

03Why include implementation loss?
Solution

Ideal formulas omit synchronization, estimation, filter and hardware imperfections.

04What if margin is negative?
Solution

The specified reliability is not supported under the assumed conditions.

05Name three remedies for insufficient margin.
Solution

Increase power/gain, reduce rate/order, use stronger coding, reduce losses, or add diversity.
