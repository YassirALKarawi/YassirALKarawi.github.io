01

Start with meaning

Why this topic matters

Channel coding adds structured redundancy so a receiver can detect or correct errors. The decoder does not create information; it exploits code constraints to choose the most plausible valid sequence from a noisy observation.

INTUITION

Ordinary words have spelling rules. If one letter is corrupted, the nearest valid word may still be obvious. A channel code designs such separation mathematically using Hamming or Euclidean distance.

02

Mathematical foundation

Equations you can trust

Read every formula as a relationship between physical quantities. Check units before inserting numbers, and keep linear ratios separate from decibels.

01

Code rate

R_c=\frac{k}{n}

k information bits become an n-bit codeword.

02

Correction capability

t=\left\lfloor\frac{d_{min}-1}{2}\right\rfloor

Maximum guaranteed random bit errors corrected.

03

Detection capability

e_{detect}=d_{min}-1

Maximum guaranteed detected errors.

04

Linear code

\mathbf c=\mathbf uG,\quad \mathbf s=\mathbf rH^T

G generates codewords; syndrome s reveals parity violations.

05

Coded throughput

R_{info}=R_cR_{coded}

Redundancy reduces net rate unless symbol rate grows.

How to study the mathematics

First name every symbol, then state the assumptions, substitute values with units, and only then calculate. A numerically correct result without assumptions is not a complete engineering answer.

From symbols to numbers

Fully worked examples

Worked example 1

(7,4) Hamming code

Problem

Find rate and correction capability when dmin=3.

  1. Rᶜ=k/n=4/7≈0.571
  2. t=floor((3−1)/2)=1
AnswerIt corrects one random bit error per codeword.
Worked example 2

Coded rate

Problem

A rate-1/2 code carries 2 Mbit/s of information. Find coded bit rate.

  1. Rinfo=RcRcoded
  2. Rcoded=2/(1/2)
AnswerThe modulator receives 4 Mbit/s.
06

Deliberate practice

Problems with guided solutions

Attempt each problem on paper before opening the solution. Include units and state the formula you selected.

01How many errors can dmin=5 correct?
Solution

floor((5−1)/2)=2.

02How many can dmin=5 detect?
Solution

Four.

03Why are soft decisions better?
Solution

They preserve reliability magnitude rather than reducing each observation to a hard bit.

04What does an interleaver combat?
Solution

Burst errors by spreading them across codewords or trellis time.

05What is coding gain?
Solution

The Eᵦ/N₀ reduction for a target BER relative to a reference uncoded system.
