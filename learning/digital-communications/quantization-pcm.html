01

Start with meaning

Why this topic matters

Pulse-code modulation maps each sampled amplitude to one of L permitted levels and encodes the level index as a binary word. Quantization is intentionally lossy: increasing word length lowers distortion but increases bit rate and required bandwidth.

INTUITION

Quantization is like measuring with a ruler whose markings have finite spacing. Values between markings must be rounded; more markings mean a smaller error but more bits are needed to name each mark.

STEP-BY-STEP DERIVATION

Uniform quantization-noise power

For a sufficiently busy input, the rounding error is modeled as uniformly distributed between −Δ/2 and +Δ/2.

  1. Write the error density

    p_e(e)=\frac1\Delta,\quad |e|\le\Delta/2

  2. The mean error is zero by symmetry

    \mathbb E[e]=0

  3. Integrate the squared error

    \sigma_q^2=\int_{-\Delta/2}^{\Delta/2}e^2\frac{de}{\Delta}

  4. Evaluate the integral

    \sigma_q^2=\frac{\Delta^2}{12}
How to study the mathematics

First name every symbol, then state the assumptions, substitute values with units, and only then calculate. A numerically correct result without assumptions is not a complete engineering answer.

01What is ideal SQNR for 8 bits?
Guided solution

About 49.92 dB.

02Why compand speech?
Guided solution

It gives small signals finer effective resolution and improves perceived SQNR.

03What happens to Δ when n rises by one bit?
Guided solution

The number of levels doubles and Δ halves for a fixed range.

Guided solution

An n-bit word labels 2ⁿ reconstruction levels.

05Draw the complete processing order from memory.
Guided solution

Anti-alias filter → Sample and hold → Quantizer → Binary encoder → PCM channel → Decoder → Reconstruction filter.

The first relation establishes an n-bit word labels 2ⁿ reconstruction levels. The second establishes uniform quantizer spacing.
